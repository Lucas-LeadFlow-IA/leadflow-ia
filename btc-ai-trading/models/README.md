# models/

Generated by `python main.py train-ml` (git-ignored except this file).

- `trade_filter.joblib` + `.json` — meta-labeling filter (enabled only if it beats the baseline out of sample)
- `regime_model.joblib` + `.json` — ML regime classifier (advisory; enabled only if it beats the rules)
- `anomaly_model.joblib` + `.json` — IsolationForest anomaly detector used by the Regime Detector when enabled
- `confidence_calibration.json` — isotonic score -> probability map (JSON, no pickle)

Each `.joblib` is loaded only if its SHA-256 matches the value stored in its `.json` metadata.
